# University emblem sources

- `dist/assets/cuhksz-emblem.png`: the complete 145 × 145 icon image extracted without visual changes from the official CUHK-Shenzhen favicon, https://www.cuhk.edu.cn/themes/custom/cuhk_ui/favicon.ico . University homepage: https://www.cuhk.edu.cn/zh-hans .
- `dist/assets/tongji-identity.png`: the original university emblem and wordmark reference published by Tongji University News, https://news.tongji.edu.cn/info/1008/94580.htm . Original image: https://news.tongji.edu.cn/__local/5/A7/F1/E3C5397E909F96DCCB79D82EF3C_7AE4B728_79D6.png . The downloaded reference file is preserved unchanged. `dist/assets/tongji-emblem.svg` embeds the reference and uses a bounded viewBox for its complete circular emblem. The SVG has an intrinsic size of 52 × 52 px, and the HTML also explicitly sets 52 × 52 px; no CSS crop is required.

The small emblems identify the universities in the education section and link to their official websites.
